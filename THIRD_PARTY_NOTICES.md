# Third-party notices

The JavaScript implementation is original code written for this application. Its UPDI constants and programming sequence were checked against:

- Microchip documentation for the Unified Program and Debug Interface and the ATtiny402, ATtiny412 and ATtiny814 device signatures, memory maps and NVM controller.
- megaTinyCore SerialUPDI documentation and the command profile supplied by the user.
- `tinyupdi.py` from Stefan Wagner's `wagiminator/MCU-Flash-Tools` project, which is published under the MIT License and is itself based on pyupdi and Microchip pymcuprog.

No third-party JavaScript libraries are bundled. The application runs using browser platform APIs only.
